Ahhh samajh gaya! 🎯

Bilkul simple concept - **jaise AirDrop ya Nearby Share hai** lekin **web-based**:

```
ezshare.vercel.app kholo
    ↓
Portal dikha
    ↓
Same WiFi ke devices detect hote hain automatically
    ↓
Apni device select kro
    ↓
File drag-drop kro
    ↓
Dusri device par instantly receive ho
```

**Key Points:**

✅ **Link sirf website access k liye** - login/auth nahi, sirf portal khul jayega
✅ **Same WiFi mein automatic detection** - apne aap connected devices dikhe
✅ **Har koi apna use kar sakta** - dost ko bol: "ezshare.vercel.app kholo same WiFi se"
✅ **Private by default** - sirf same network wale dekh sakein
✅ **No accounts** - koi registration nahi

---

## **Kaise Kaam Karega:**

```
Your PC (192.168.1.5:3000)
├─ Open: ezshare.vercel.app
├─ Portal: "Available Devices"
│   ├─ Your Phone ✓
│   ├─ Friend's Phone ✓
│   └─ Laptop ✓
└─ File drag → instantly send

Your Friend's Phone (same WiFi)
├─ Open: ezshare.vercel.app
├─ Portal: "Available Devices"
│   ├─ Your PC ✓
│   ├─ Your Phone ✓
│   └─ Laptop ✓
└─ File receive automatically
```

---

## **Backend Technology:**

**WebSocket** use hoga (real-time):

```javascript
// PC se:
socket.emit('send-file', {
  to: 'friend-phone-id',
  file: fileData
})

// Friend's phone automatically:
socket.on('receive-file', (data) => {
  // File download ho jayega
})
```

---

## **Simple Architecture:**

```
Frontend (React): ezshare.vercel.app
    ↓
WebSocket Server (same WiFi detect karne k liye)
    ↓
Devices automatically connect
    ↓
P2P File Transfer (direct device-to-device)
```

## Tech Stack

* **Frontend:** Next.js 15 + React
* **UI:** Tailwind CSS + Framer Motion + shadcn/ui
* **Realtime Signaling:** Socket.io
* **P2P Transfer:** WebRTC Data Channels
* **QR Code:** `qrcode` + `html5-qrcode`
* **Deployment:**

  * Frontend → Vercel
  * Signaling Server → Railway (ya Render)
